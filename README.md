# Magic-Proxy
Software para hacer proxys de magic\
Si tenes ganas de jugar magic pero no tenes plata para las cartas esto es para vos.\
Lo que hace este software es tomar un mazo de un archivo .txt y te genera un pdf listo para imprimir.\
Entre los archivos vas a encontrar el codigo fuente, un ejemplo y el ejecutable para usar\
El pdf generado tiene una primer pagina por si queres imprimir la parte de atras, sino ignorala.\
Tambien tiene lineas guia para cortar con cutter.\
Si una carta necesita tokens adicionales te va a preguntar cuantas copias queres.
