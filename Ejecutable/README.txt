# Proxy Deck

This tool allows you to download Magic: The Gathering cards and automatically generate a printable PDF with 3x3 cards per page.

## How to use:

1. Go to https://manabox.app and create or import your deck.
2. Download your deck as a `.txt` file.
3. Place the `.txt` file in the same folder as the `Proxy Deck.exe`.
4. Run `Proxy Deck.exe` – a folder with your printable PDF will be created automatically.

Enjoy your proxies!
